# Personal Site API

## User Endpoints

- About me (GET /home)
- Projects (GET /projects)
- Thoughts (GET /thoughts)
- Music Flavours (GET /music)

Note, projects and thoughs can have their own slugs too

# Bonus Admin Endpoints

- Monitoring (GET /watchdog)
- Create new thoughts, edit and delete (POST /post, PUT /post/{slug}, DELETE /post/{slug})
